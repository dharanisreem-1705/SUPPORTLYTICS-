**Supportlytics – IT Support Performance Analytics Dashboard**

Supportlytics is an end-to-end IT Support Performance Analytics and Business Intelligence project developed as part of my Infosys Springboard Virtual Internship Program. The project analyzes synthetic IT support ticket data using Python, Jupyter Notebook, and Power BI, and demonstrates the complete analytics workflow from data preparation and exploratory analysis to performance insights and interactive dashboard visualization.

**Internship Information**

Internship: Infosys Springboard Virtual Internship Program
Project: Supportlytics – IT Support Performance Analytics Dashboard
Domain: Data Analytics & Business Intelligence

**Project Objective**

The objective of this project is to analyze IT support ticket operations and generate actionable insights that help improve ticket resolution efficiency, customer satisfaction, regional performance, and support resource allocation through data-driven decision-making.

**Milestone Progress**

**Milestone 1 – Data Collection & Cleaning**

- Loaded the IT support ticket dataset
- Explored the dataset structure and schema
- Handled missing values
- Created derived features such as "Resolution_Duration" and "Priority_Score"
- Prepared a clean dataset for analysis

**Milestone 2 – Exploratory Data Analysis (EDA)**

- Analyzed ticket distribution across categories and issue types
- Studied ticket status and priority patterns
- Explored customer sentiment and CSAT trends
- Created visualizations using Matplotlib and Seaborn

**Milestone 3 – Performance Trend & Geographic Insights**

- Analyzed average resolution time by priority, issue type, region, and support queue
- Identified high and urgent unresolved ticket categories
- Evaluated regional performance metrics
- Created ticket concentration heatmaps
- Mapped issue categories geographically using latitude and longitude
- Analyzed cluster size versus performance score
- Generated comparative charts and performance summary tables

**Milestone 4 – Power BI Dashboard Development**

- Designed and developed a 7-page interactive Power BI dashboard
- Created an Executive Overview with KPI cards and summary visuals
- Built dashboards for Resolution Time Analysis, Ticket Categories, Geographic Insights, Cluster Similarity, and Regional Performance
- Implemented interactive page navigation and dashboard-based storytelling
- Delivered a complete business intelligence solution for IT support performance monitoring

**Power BI Dashboard Pages**

1. Executive Overview
2. Resolution Time Analysis
3. Ticket Categories & Distribution
4. Geographic Insights
5. Cluster Similarity Analysis
6. Regional Performance Dashboard
7. Insights & Recommendations

**Key Insights**

- Identified the most frequent support ticket categories
- Compared ticket priority distribution across the organization
- Evaluated average resolution time by region and issue type
- Detected high-volume regions requiring additional support resources
- Measured cluster similarity and performance relationships
- Compared regional customer satisfaction and operational efficiency
